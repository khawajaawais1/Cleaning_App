================================================================================
GETTING STARTED
================================================================================

1. Prerequisites:
   - .NET 8 SDK
   - SQL Server LocalDB (included with Visual Studio)

2. Setup:
   cd Happy2CleanAPI
   dotnet restore
   dotnet build

3. Run:
   dotnet run
   OR
   dotnet watch run (development)

4. Access API:
   https://localhost:5001 (Swagger UI)
   Login: admin@happy2clean.com / Admin123!
